# 🩸 RaktKosh – Blood Donation & Management System

A web-based blood bank and donor management platform designed to streamline donor registrations, track blood unit availability, and manage requests efficiently.

---

## 🚀 Features

- **Donor Registration & Profiles:** Collect and verify donor details, blood groups, and donation eligibility.
- **Inventory & Stock Management:** Monitor blood units by group with real-time availability updates.
- **Request Processing:** Manage patient/hospital blood requests with status tracking.
- **Administrative Dashboard:** View system analytics, donor metrics, and inventory logs.

---

## 🛠️ Built With

- **Backend:** PHP, Laravel Framework
- **Frontend:** Blade Templates, Bootstrap, CSS3, JavaScript
- **Database:** MySQL
- **Environment:** XAMPP, Git
